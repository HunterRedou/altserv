# WP-12: Staging load test

Status: blocked
Phase: 2
Depends on: WP-09

## Goal
Measure the latency and error rate on staging with database telemetry.

## Read
- `cmd/loadgen/main.go`
- `docs/runbooks/load-testing.md`

## Do
1. Run `cmd/loadgen` from a host in the same region, against the load
   balancer.
2. Use the mixed paths and the patient list path, as in the local run.
3. Record p95, p99, error rate, DB CPU and connection count.
4. Compare with the loopback numbers in `docs/runbooks/load-testing.md`.

## Test
- No 5xx during the run.

## Done when
- The result table is in `docs/runbooks/load-testing.md` with the instance size.

## Do not
- Run the load test against production.
