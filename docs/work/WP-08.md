# WP-08: Terraform RDS

Status: blocked
Phase: 2
Depends on: WP-07, WP-01, WP-04

## Goal
Terraform makes the RDS for PostgreSQL instance with the settings that cannot
change later.

## Read
- `docs/work/decisions.md` (D-1, D-2)
- `docs/compliance/backup-policy.md`
- `deployments/sql/roles.sql` (from WP-04)

## Do
1. Make `deployments/terraform/database/`.
2. Use the PostgreSQL major version that the tests use.
3. Set: KMS encryption with a customer key, no public access,
   `rds.force_ssl=1`, deletion protection, final snapshot on delete.
4. Set the backup retention from `docs/compliance/backup-policy.md` (14 to 35 days).
5. Set Multi-AZ from the D-1 answer.
6. Keep the master password in Secrets Manager (RDS managed secret).
7. Write the steps for `deployments/sql/roles.sql` and goose into `docs/runbooks/deployment.md`.

## Test
- `terraform plan` shows encryption, retention and deletion protection.
- After apply: connect with `sslmode=verify-full`, and run goose as
  `altserv_migrator`.

## Done when
- All 27 migrations run on RDS.
- `TestRuntimeRoleCannotEscalate` passes against RDS.

## Do not
- Let the app use the master user.
