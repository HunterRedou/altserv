# WP-18: Operator-only tenant

Status: blocked
Phase: 3
Depends on: D-7, WP-05

## Goal
Platform staff log in to a tenant that has no patients and no care data.

## Read
- `docs/work/decisions.md` (D-7)
- `docs/platform-admin-patient-access-reminder.txt`
- `internal/breakglass/service.go`

## Do
1. Add a tenant flag or kind `operator`.
2. Refuse patient, visit, report and billing writes in an operator tenant.
3. Add the operator tenant to `cmd/tenantadmin`.
4. Implement the support path from D-7. Keep break-glass explicit, time
   limited and audited.

## Test
- A patient write in an operator tenant fails.
- A `platform_admin` in the operator tenant cannot read another tenant's
  patients without a break-glass grant.

## Done when
- The tests pass.

## Do not
- Give `platform_admin` automatic access to health data.
