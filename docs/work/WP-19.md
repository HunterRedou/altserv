# WP-19: Art. 15 export

Status: open
Phase: 3
Depends on: none

## Goal
A chef can answer a data-subject access request (Art. 15 GDPR) for one
patient.

## Read
- `docs/compliance/processing-activities.md`
- `internal/patients/service.go`
- `internal/reports/service.go`

## Do
1. First write a manual procedure in `docs/runbooks/data-subject-access.md`.
2. Then add `GET /api/patients/{id}/access-export` for a chef only. It returns
   the patient data, visits, reports and the audit events about the patient.
3. Decrypt only inside the request. Do not store the export.
4. Write one audit event `patient.access_export`. Metadata: ids only.

## Test
- An employee and a `platform_admin` get 403.
- A chef of another tenant gets 404.
- The audit metadata contains no name.

## Done when
- The procedure exists. The endpoint is optional for the pilot.

## Do not
- Export data of other patients.
