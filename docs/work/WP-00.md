# WP-00: Rotate the local keys

Status: open
Phase: 0
Depends on: none

## Goal
Replace the local keys that the old `/app/` file server exposed (fix `6c24b1a`).

## Read
- `.env.example`
- `docs/runbooks/key-rotation.md`
- `docs/decisions/ADR-025-synthetic-development-data.md`

## Do
1. Make a new 32-byte value for `PATIENT_ENCRYPTION_KEY` with `openssl rand -base64 32`.
2. Make a new, different value for `PATIENT_SEARCH_KEY`.
3. Make a new, different value for `MFA_ENCRYPTION_KEY` if `.env` sets it.
4. Write the new values into `.env`.
5. Empty the dev database `gator`, then run the migrations again.
6. Run `cmd/devseed` again.

## Test
- Log in as `employee@demo.invalid`. The patient list shows decrypted names.

## Done when
- No old key value is in `.env`.
- The demo login works.

## Do not
- Commit `.env`.
- Re-encrypt the old demo data. Delete it and seed again.

## Notes
The old keys protected synthetic data only. If a real key was ever used with a
server started from the repository folder, follow `docs/runbooks/key-rotation.md` instead.
