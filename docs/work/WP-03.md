# WP-03: Send HSTS in production

Status: open
Phase: 0
Depends on: none

## Goal
In production, browsers use only HTTPS after the first visit.

## Read
- `middleware_security_headers.go`
- `middleware_hardening_test.go`

## Do
1. Find how the middleware can know the platform (`cfg.platform`).
2. When the platform is `prod`, set
   `Strict-Transport-Security: max-age=31536000; includeSubDomains`.
3. When the platform is `dev`, do not set the header. A dev browser on
   `localhost` must not remember HSTS.

## Test
- `TestSecurityHeadersHSTSOnlyInProd`: the header is present in prod and absent
  in dev.

## Done when
- The test passes.
- `docs/security-review.md` lists HSTS in the results table.

## Do not
- Add `preload`. Preload is hard to undo; decide it later.

## Notes
TLS ends at the edge (load balancer). HSTS from the app is still correct,
because the browser only accepts it over HTTPS.
