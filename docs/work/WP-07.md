# WP-07: Terraform network

Status: blocked
Phase: 2
Depends on: D-1

## Goal
Terraform makes a VPC in eu-central-1 with private subnets for the database
and the app.

## Read
- `docs/work/decisions.md` (D-1 answer only)
- `deployments/README.md`

## Do
1. Make `deployments/terraform/network/`.
2. Make one VPC, two private subnets in two availability zones, and the public
   subnets that the load balancer needs.
3. Make a security group for the database. It allows port 5432 only from the
   app security group.
4. Store the Terraform state in an encrypted S3 bucket with locking.
5. Write outputs: VPC id, subnet ids, security group ids.

## Test
- `terraform validate` and `terraform plan` run without errors.

## Done when
- `plan` shows only the expected resources.

## Do not
- Give the database a public IP.
- Commit state files or credentials.
