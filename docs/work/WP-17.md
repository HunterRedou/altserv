# WP-17: Mail provider adapter

Status: blocked
Phase: 3
Depends on: WP-06, D-1

## Goal
The app sends real mails through an EU mail provider (for example Amazon SES
in eu-central-1).

## Read
- `internal/mail/` (from WP-06)
- `docs/compliance/processing-activities.md`

## Do
1. Add an adapter for the provider behind the `Mailer` interface.
2. Use a verified sender domain with SPF, DKIM and DMARC.
3. Add `MAIL_ADAPTER=<provider>` and its config. Keep secrets in Secrets
   Manager.
4. List the provider in `docs/compliance/processing-activities.md` and E-4.

## Test
- A unit test with a fake transport checks the request.
- A staging password reset reaches a test inbox.

## Done when
- Staging sends a reset mail.

## Do not
- Send health data or patient names by mail.
