# WP-11: Backup alarm

Status: blocked
Phase: 2
Depends on: WP-08

## Goal
An alarm fires when the newest restorable time is too old or a backup fails.

## Read
- `docs/compliance/backup-policy.md`
- `deployments/monitoring/` (the alert rules)

## Do
1. Make a CloudWatch alarm or an EventBridge rule for RDS backup events.
2. Send the alarm to the alert receiver chosen in WP-09 or D-1.
3. Write in `docs/compliance/backup-policy.md` that `BACKUP_MARKER_FILE` is not used on RDS.

## Test
- Trigger the alarm once (for example with a test event). Record the result.

## Done when
- The alarm reached a person once.

## Do not
- Add the AWS SDK to the app for this.
