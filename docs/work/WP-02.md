# WP-02: Require METRICS_TOKEN in production

Status: open
Phase: 0
Depends on: none

## Goal
`/metrics` is never public in production.

## Read
- `internal/config/validation.go`
- `internal/config/config_test.go`
- `.env.example`

## Do
1. In `validate()`, reject an empty `METRICS_TOKEN` when `PLATFORM=prod`.
2. Keep the minimum length check (16 characters).
3. Change the comment in `.env.example` from "Optional" to "Required in
   production".

## Test
- `TestLoadRequiresMetricsTokenInProd`: prod without a token fails; prod with a
  16-character token starts; dev without a token starts.

## Done when
- Prod without `METRICS_TOKEN` fails at startup.
- Existing tests that load prod config still pass. If one fails, give it a
  token.

## Do not
- Change the `/metrics` handler.
