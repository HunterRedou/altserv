# WP-09: App runtime and secrets

Status: blocked
Phase: 2
Depends on: WP-08

## Goal
The app runs on AWS. All keys and the DB password come from Secrets Manager.

## Read
- `docs/work/decisions.md` (D-1)
- `internal/config/config.go`
- `deployments/docker/Dockerfile`

## Do
1. Make `deployments/terraform/app/` for the runtime chosen in D-1.
2. Put `PATIENT_ENCRYPTION_KEY`, `PATIENT_SEARCH_KEY`, `MFA_ENCRYPTION_KEY`,
   `METRICS_TOKEN` and the runtime `DB_URL` in Secrets Manager.
3. Inject the secrets into the runtime. With ECS, use the task `secrets`
   field. Do not put a secret in plain environment variables in Terraform.
4. Put the load balancer in front of the app with TLS (ACM certificate).
5. Set `PLATFORM=prod` and `BILLING_TRANSMISSION_ADAPTER=unconfigured`.

## Test
- `/readyz` answers 200 through the load balancer.
- `/app/.env` answers 404.
- `/metrics` without a token answers 401.
- The response has the HSTS header.

## Done when
- The staging app runs with synthetic data from `cmd/devseed`. `devseed` needs
  `PLATFORM=dev`, so use a separate staging task for the seed.

## Do not
- Use real patient data.
