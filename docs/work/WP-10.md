# WP-10: PITR drill script and record

Status: blocked
Phase: 2
Depends on: WP-08, D-2

## Goal
A script runs a point-in-time restore drill on RDS and writes a record.

## Read
- `docs/runbooks/database-recovery.md`
- `deployments/docker/restore-drill.sh` (as the pattern)
- `docs/work/decisions.md` (D-2)

## Do
1. Write `deployments/aws/pitr-drill.sh`.
2. The script writes marker row 1, waits, notes the time, writes marker 2.
3. It waits until `LatestRestorableTime` is after the noted time.
4. It runs `aws rds restore-db-instance-to-point-in-time` to a new instance.
5. It checks: marker 1 is present, marker 2 is absent, RLS is still forced.
6. It measures the RTO from the start of the restore to the first query.
7. It writes `docs/drills/YYYY-MM-DD-pitr.md` with target time, RPO, RTO and
   the result.
8. It deletes the drill instance, also when a check fails.

## Test
- Run the drill once on staging. The record shows "pass".

## Done when
- One record exists. The RTO is compared with the D-2 value.

## Do not
- Restore over the source instance.
- Write patient data as marker rows. Use a dedicated marker table.
