# WP-06: Mail interface and fake mailer

Status: open
Phase: 0
Depends on: none

## Goal
The app sends password-reset and MFA-change mails through an interface. A
provider adapter follows in WP-17.

## Read
- `handler_password_reset.go`
- `internal/config/config.go`
- `step2_flow_db_test.go` (only the password-reset tests)

## Do
1. Add `internal/mail` with an interface `Mailer` and a `Message` type
   (to, subject, text body).
2. Add `FakeMailer` (records messages, for tests) and `LogMailer` (dev only).
   `LogMailer` logs the recipient and subject. It does not log the body,
   because the body contains the reset link.
3. Send a mail on password-reset request and on MFA enable or disable.
4. Write the mail texts. They contain no patient name and no health data.
5. Add `MAIL_ADAPTER` with the values `log` and `none`. Prod rejects `log`.

## Test
- A reset request sends one message to the right address.
- An unknown address sends no message and gives the same HTTP answer.
- The log output does not contain the reset token.
- Prod with `MAIL_ADAPTER=log` fails at startup.

## Done when
- The tests pass.

## Do not
- Add a real provider. WP-17 does that.
